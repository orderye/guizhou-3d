## V3.6.0 — 2026-09-27(缩放流畅度轮)

### 优化
- **地形重建时间切片**:LOD 变更瓦片不再同帧同步重建,进入重建队列(去重 + 按相机距离排序,近者优先),渲染循环每帧在 7ms 预算内逐瓦片生成——缩放全程 FPS 曲线 55→60 无深谷(此前跨级缩放会出现 300ms+ 停顿、36 FPS)
- **初始加载渐进化**:init 直接入队目标级别,瓦片随渲染循环逐块出现(与 intro 缓降配合无冻结帧)
- **水系/道路距离带磁滞**:进/出阈值分离(1↔2 边界 12/15,2↔4 边界 30/38),消除阈值附近往返重建
- **森林显隐磁滞**:显示 <40u / 隐藏 >47u,防边界闪烁
